# NEON HOOPS 7.5 — отдельный онлайн-сервер на Northflank

Этот проект содержит **и игру, и полноценный Node.js WebSocket-сервер комнат**.
Ничего не пересылается через Render или Layero. Оба игрока открывают ОДИН и ТОТ ЖЕ адрес нового проекта.

## Установка

1. ЗАГРУЗИ файлы из архива в **новый репозиторий GitHub** (например, `neon-hoops-northflank`) или заменяй ими корень прежнего, если хочешь синхронизировать оба сервера. Важно: `index.html`, `server.js`, `package.json`, `Dockerfile`, `.dockerignore` должны лежать в **корне**, а не внутри вложенной папки.
2. Открой https://app.northflank.com/ , создай проект на тарифе **Sandbox (Free)**. Для европейских игроков попробуй **Europe West Frankfurt**, альтернативно Europe West Netherlands. Выбирай регион по тому, где ближе ОБА игрока и к какому хосту есть доступ без VPN.
3. В проекте **Create new → Service → Combined**. Подключи GitHub и ветку `main`. Тип сборки — **Dockerfile**, путь `Dockerfile`.
4. Настрой **Public HTTP port 3000** (Protocol `HTTP`, Public), назначь публичный домен (Northflank обычно выдаёт `*.code.run`). Ровно **одна реплика/instance**: комнаты хранятся в памяти сервера, второй экземпляр разделит игроков.
5. Начальная команда уже в Dockerfile: `node server.js`. В переменных окружения `PORT=3000` (либо другой номер, если на платформе настроен иной порт — должен совпадать с Public HTTP port).
6. Включи health check `/health` (HTTP), если есть выбор. Успешный ответ вида `{"ok":true,"version":"7.5","websocket":true}` говорит, что HTTP-сервер работает, но WebSocket обязательно проверяй кнопкой **«ПРОВЕРИТЬ СВЯЗЬ»** в меню игры.
7. Открой **новый домен Northflank** (не Layero). Выбери «Онлайн 1 на 1», проверь, что поле сервера содержит адрес этого же сайта, и нажми «Проверить связь». Сделай проверку **без VPN на обоих компьютерах**. Затем создай комнату и пришли другу ссылку.

## Если не работает

- Сайт открывается, но WebSocket 1006: проверь Public HTTP port, маршрут `/ws`, режим HTTP(S), настройки прокси; не пытайся играть через Layero — тот не предназначен для игровых WebSocket-серверов.
- Комната не найдена: убедись, что у всех **одна и та же ссылка/сервер**, и что запущена **1 реплика**.
- Сильный пинг: сравни регионы. FPS на ПК и ping — разные показатели. Для реального теста оба должны быть без VPN. Реальный пинг нельзя гарантировать заранее.
- При пересборке сервера активные комнаты сбрасываются.

## Проверить локально

`node server.js` → `http://localhost:3000/health` → `http://localhost:3000/`.
Для Docker: `docker build -t neon-hoops .` и `docker run --rm -p 3000:3000 neon-hoops`.
